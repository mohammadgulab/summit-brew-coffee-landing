# Summit Brew Coffee — Landing Page

A responsive one-page landing page for **Summit Brew**, a fictional coffee roaster, designed and built by Mohammad Gulab as a portfolio piece.

- Plain HTML and CSS, no build step: open `index.html` in a browser.
- Mobile-first layout, Google Fonts (Montserrat + Playfair Display).
- The logo and icon are from my Summit Brew brand identity set.

**Live demo:** https://mohammadgulab.github.io/summit-brew-coffee-landing/
